# 整列展開樣稿

依2026-10-26使用者截圖與要求，先提供可點選的版型樣稿；尚未採用到原版首頁或正式GitHub網站。

選取稻浪方格後，在該列方格下方插入橫跨整列的詳情面板，避免單欄長內容造成左右空洞。桌面內容三欄，平板二欄，手機一欄；內容區桌面250px、平板290px、手機300px，超出時在面板內捲動。三個分類切換「重點總覽／拍攝規劃／注意與來源」，保留所有原稻浪資料、來源、稻況待確認與橙紅藍分色；下方其他方格不被無限推遠。

只開一處；點原卡或收合鍵可關閉；篩選時關閉，變更視窗寬度時依新列數定位。頁籤支援方向鍵、Home、End；Escape收合。初始顯示花東金剛大道，便於比較使用者截圖。

這是可拋棄的互動樣稿，只對七處稻浪景點示範；其他原景點維持既有互動。index.html保留；樣稿入口layout-preview.html。
